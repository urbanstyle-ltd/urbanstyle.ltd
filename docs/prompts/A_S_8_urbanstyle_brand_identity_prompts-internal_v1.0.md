| Pillar | Meaning | Visual Translation |

- **If UrbanStyle were a person:** A 27-year-old Tallinn creative who studied architecture, skates to work, wears one perfectly chosen outfit, speaks quietly but gets noticed.
- **Voice:** Confident but not loud. Knows quality. Doesn't try too hard.
- **NOT:** Flashy, hypebeast, fast fashion, mass market, corporate, generic Scandi-minimal.

## TYPOGRAPHY

### Primary: Heading / Display
**Font:** `PP Neue Montreal` (or similar: Satoshi, General Sans, Switzer)
- Weight: Bold (700) for headlines, Medium (500) for subheads
- Case: UPPERCASE for short headlines, Sentence case for longer
- Tracking: +0.02em for uppercase, normal for sentence case
- **Prompt term:** "contemporary geometric sans-serif, clean, slightly condensed"

### Secondary: Body / UI
**Font:** `Inter` or `DM Sans`
- Weight: Regular (400) for body, Medium (500) for labels
- Size: 16px base
- **Prompt term:** "clean modern sans-serif, highly legible"

### Accent: Mono / Data
**Font:** `JetBrains Mono` or `IBM Plex Mono`
- Use for: prices, data points, technical specs, code snippets
- **Prompt term:** "monospace font, technical, data aesthetic"

### Typography Rules
- Never use serif fonts
- Never use script/handwritten fonts
- Never use more than 2 font families on one page
- Letter-spacing on CAPS headings is mandatory
- Line height: 1.5 for body, 1.1 for display

## BRAND PHOTOGRAPHY STYLE

### Direction
| Element | Guideline |
|---------|-----------|
| **Light** | Natural first. Golden hour and overcast preferred. Studio = soft directional, never flat. |
| **Color grade** | Slightly desaturated, warm shadows, cool highlights. Never oversaturated. |
| **Composition** | Rule of thirds, generous negative space. Subject never centered unless symmetry is intentional. |
| **Backgrounds** | Concrete, limestone, raw wood, glass/steel modern. Never busy/cluttered. |
| **Models** | Natural, diverse, confident-not-posed. Movement > stillness. |
| **Mood** | Quiet confidence. Not aggressive, not passive. "I chose this, and I know why." |
| **Post-production** | Subtle grain (ISO 400 feel). Never HDR. Never heavy retouching. Skin texture visible. |

### Photography DON'Ts
- No ring light catchlights
- No heavy filter/preset looks (VSCO, etc.)
- No obvious posing/fashion clichés
- No studio backdrops with fake environments
- No composite/Photoshop montages
- No Dutch angles
- No muted-to-grey desaturation (still needs warmth)

## WEBSITE DESIGN LANGUAGE (urbanstyle.ltd)

### Layout Principles
- **Grid:** 12-column, generous gutters (24px+)
- **White space:** Aggressive. Let content breathe. More space = more premium.
- **Sections:** Full-bleed images alternating with contained text blocks
- **Scroll behavior:** Smooth, parallax on hero images, fade-in on scroll for products
- **Mobile:** Design mobile-first, but desktop is the showcase

### UI Components Style

| Component | Style |
|-----------|-------|
| **Buttons** | Rounded-rect (8px radius), charcoal fill, off-white text. Hover: burnt orange. |
| **Cards** | No border, subtle shadow (0 2px 16px rgba(0,0,0,0.06)), rounded 12px |
| **Images** | Rounded 8px corners, never squared, never circular |
| **Navigation** | Sticky top, transparent → charcoal on scroll, minimal items |
| **Footer** | Charcoal bg, off-white text, 4-column grid, newsletter signup |
| **Hover effects** | Subtle scale (1.02) on products, underline-slide on text links |
| **Transitions** | 300ms ease, never instant, never slow |

6. **Patterns & textures** → background assets
7. **Packaging** → physical brand world
8. **Website mockups** → digital brand world
9. **Social templates** → marketing assets
