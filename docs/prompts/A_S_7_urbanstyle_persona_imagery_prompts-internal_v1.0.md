# UrbanStyle OÜ — Persona Character Reference Sheet Prompts v1.0

**Purpose:** Gen-AI character reference images for simulation consistency
**Tools:** Midjourney v6.1 / Flux Pro 1.1 / Ideogram 2.0
**Method:** Generate reference sheet FIRST → use as image reference for all subsequent shots
**Goal:** Consistent recognizable faces across all materials (website, emails, presentations, showreels)

---

## WORKFLOW: HOW TO USE THIS FILE

### Step 1: Generate Character Reference Sheets (Turnaround Sheets)
Generate the `REF` prompt for each character FIRST. This gives you front/¾/side/back views on one image.

### Step 2: Lock the Face
Use the reference sheet as `--cref` (character reference) in Midjourney, or as an image prompt in Flux/Ideogram for ALL subsequent generations of that character.

### Step 3: Generate Situational Shots
Use `OFFICE`, `CASUAL`, `EXPRESSION`, `ACTION` prompts WITH the reference image to maintain consistency.

### Step 4: Cross-Character Scenes
For group shots (meetings, presentations), reference ALL characters involved.
