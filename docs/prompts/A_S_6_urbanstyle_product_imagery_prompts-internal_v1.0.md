## PRODUCTION NOTES

### Recommended Generation Order
1. **Model polaroids first** (A, B, C, D) — establish consistent faces
2. **Hero products on clean backgrounds** (all *A shots) — catalog base
3. **Detail close-ups** (all *B shots) — quality storytelling
4. **Lifestyle/location shots** (all *C shots) — brand world
5. **Lookbook campaign shots** (L1–L4) — multi-product narratives
6. **Showreel stills** (V1–V5) — video content base
7. **Flat lays and editorials** — social media / website fillers

### Consistency Tips
- Generate model polaroids, then use as reference images for all subsequent shots
- Keep Tallinn locations consistent (Old Town, Kalamaja, Telliskivi, Noblessner, Rotermann)
- Maintain color palette: charcoal, off-white, sage, slate blue, burnt orange
- Always use `--style raw` for editorial/realistic output
- For video stills, always use `--ar 16:9` and add "cinematic" modifier

### Output for Website
- Hero banners: 16:9 @ 2560px wide
- Product cards: 3:4 @ 1200px wide
- Detail squares: 1:1 @ 1200px
- Mobile full-bleed: 9:16 @ 1080px wide

### Showreel Assembly
Use video stills V1–V5 as keyframes, generate intermediate frames with:
- Runway ML Gen-3 Alpha
- Pika Labs
- Kling AI
For 15-30 sec brand showreel: V1 (3s) → V2 (3s) → V3 (4s) → V4 (3s) → V5 (3s)
